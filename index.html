Firewall Documentation System — Synthetic Demo

This is a look-alike clone of the internal Firewall Documentation System, rebuilt with 100% synthetic data. It mirrors the navigation and feature set — Firewalls, Zone App (system classification wizard), Search (query grammar) — of the real portal shown in the source screenshots.
Read-only, existing rules only. Nothing is ever uploaded here. Firewall-change requests (fw_template.xlsx) go to a separate site — FRVA (FW Rule Verification Agent), a different URL with its own chat section — which reads this site as its temporary-RAG data source and posts its verdict, analysis and report there, not here.
