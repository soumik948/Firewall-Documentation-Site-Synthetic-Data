Firewall Documentation System — Synthetic Demo

This is a look-alike clone of the internal Firewall Documentation System, rebuilt with 100% synthetic data for the Sentrywall proof-of-concept. It mirrors the navigation and feature set — Firewalls, Zone App (system classification wizard), Search (query grammar) — of the real portal shown in the source screenshots.

What's in this demo

SectionWhat it shows
Firewalls Synthetic firewall inventory grouped like the real portal (DC / OLD / Cloud), each with interfaces & zones, object groups, routing table and access rules.
Zone App The same Yes/No classification wizard for a new system or service, ending in a Zone verdict (A / A2 / B / B2 / C).
Search The same query grammar (src: / dst: / serv: / action: / fw:) over the synthetic host/rule/group dataset.
Request Checker Points to the actual Sentrywall agent app — this documentation clone does not run analysis itself.
